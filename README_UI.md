# 🎨 دليل واجهة يلا گول — نظام التصميم «ليلة المباراة»

هذا الملف يشرح كيف بُنيت الواجهة الجديدة وأين تغيّر أي شيء فيها بسهولة. الواجهة تتكوّن من ثلاثة أجزاء
متناسقة بصرياً: **صفحة التطبيق** (`index.html` داخل WebView)، **المشغّل الداخلي** (Java أصلي)، و**حوارات التحديث** (Java أصلي).

## الهوية البصرية

الألوان مستمدة من **شعار التطبيق نفسه** (درع أزرق + مسار برتقالي) فوق ليل ملعب أزرق داكن:

| الرمز | القيمة | الاستعمال |
|---|---|---|
| `--ink-0 … --ink-4` | `#050A1B` ← `#21336E` | طبقات الخلفية والبطاقات |
| `--cobalt` (+ `-2/-3/-lo`) | `#2F6BFF` | الأزرار الرئيسية والعنصر النشط |
| `--ember` (+ `-2`) | `#FF8A1F` | لمسات الطاقة: أرقام «نشطون الآن»، شارة الموصى به |
| `--gold` | `#FFC94D` | النجمة (المفضلة) والتقييم |
| `--live` | `#FF3B55` | شارة «مباشر» |
| `--ok / --warn / --bad` | `#2FD89B / #FFB020 / #FF5A6E` | حالات الاشتراك والأخطاء |

الخطوط (مضمّنة داخل الملفات، لا تحتاج إنترنت):
**Lalezar** للعناوين والأرقام (طابع رياضي) و**Readex Pro** لبقية النصوص.

## تغيير الألوان والخطوط

- **صفحة الويب:** كل شيء من المتغيّرات في أول `:root { … }` داخل `<style>` في `app/src/main/assets/index.html`.
  غيّر القيمة هناك فتتغيّر الواجهة كلها.
- **الجزء الأصلي (المشغّل والحوارات):** نفس الألوان ثوابت في `YgUi.java` (`COBALT`, `EMBER`, …).
  عند تغيير لون هوية غيّره في المكانين ليبقيا متطابقين.
- لون الإشعارات: `res/values/colors.xml` ← `notification_color`. وخلفية النظام: `res/values/styles.xml`.

## بنية `index.html`

1. `<style>`: الخطوط (base64) ← المتغيّرات والقاعدة ← الهيكل (ترويسة/بحث/تصنيفات/دوك) ← المكوّنات ←
   الشاشات (افتتاحية/دخول/إعدادات/تفاصيل) ← التجاوب.
2. مجموعة الأيقونات: `<svg>` مخفي في بداية `<body>` يضمّ `<symbol id="i-اسم">`.
   الاستعمال في HTML: `<svg class="i"><use href="#i-search"/></svg>`، وفي JS: `ic('search')`.
3. هيكل الصفحة بالمعرّفات التي يعتمد عليها الكود (`channelsBox`, `categoryMenu`, `settingsScreen`, …).
4. `<script>`: المنطق. أُعيدت كتابة طبقة العرض بالكامل، أما منطق الشبكة/الأمان/التشغيل/Xtream فبقي كما هو حرفياً.

### عقد الواجهة مع Java (لا تغيّر هذه الأسماء)

يستدعيها `MainActivity` مباشرة من الصفحة: `checkAuth()` · `initUserStats()` · `window.__ygOnStatsUpdate(total, active)` ·
`closeIframeAndReturnToList()` · `window.__ygHandleAppBack()` · `window.__ygIsIframeOpen`.
وخط البناء (`protect-assets.js`) يحتاج وجود كتلة `<script>` وكتلة `<style>` مضمّنتين في الملف.

### أمور شائعة

- **إضافة أيقونة:** انسخ محتوى SVG من مكتبة [Lucide](https://lucide.dev) (رخصة ISC) وأضفه كـ `<symbol id="i-الاسم" viewBox="0 0 24 24">`.
- **إضافة خيار للإعدادات:** أضف عنصراً لمصفوفة `PLAYER_MODES` / `CHANNEL_DISPLAY_MODES` / … في `<script>` (حقول `id`, `name`, `desc`, `icon`).
- **لا Tailwind ولا Font Awesome ولا Google Fonts:** الصفحة بلا أي مورد خارجي ما عدا صور القنوات وملفات البيانات.

## الجزء الأصلي (Java)

| الملف | وظيفته |
|---|---|
| `YgUi.java` | الألوان والخطوط وأشكال الزجاج/اللوحات وتأثير الضغط |
| `YgIcons.java` + `YgIconView.java` | أيقونات متجهية تُرسم بـ Canvas (نفس أيقونات الويب) |
| `YgSeekView.java` | شريط التقدّم: مسار + تخزين مؤقت + تدرّج أزرق/برتقالي |
| `YgSpinnerView.java` / `YgMeterView.java` / `YgProgressView.java` | دائرة التحميل، عمود السطوع/الصوت، شريط تقدّم التحديث |
| `YgDialog.java` | حوارات «تحديث متوفر / التقدّم / الخطأ» بدل حوارات النظام الرمادية |
| `InternalPlayerActivity.java` | المشغّل: عناصر زجاجية + إيماءات + لوحة إعدادات |

الخطوط الأصلية في `app/src/main/assets/fonts/` (`ReadexPro-Medium.ttf`, `ReadexPro-Bold.ttf`, `Lalezar-Regular.ttf`).
إن فُقد أي ملف خط يرجع التطبيق تلقائياً لخط النظام دون أي انهيار.
