# دليل إضافة سيرفرات Xtream لتطبيق يلا گول

## الفكرة

بالضبط بنفس منطق `channels.json` و`quran.json` و`peoms.json`: ملف JSON واحد على
GitHub، يقرأه التطبيق تلقائياً في كل مرة يُفتح فيها (ضمن نفس دفعة التحميل مع بقية
المصادر)، ويعرض محتواه داخل مجلد جديد اسمه **"سيرفرات Xtream"** في الشاشة الرئيسية.
لا حاجة لتحديث التطبيق ولا لأي كود إضافي — فقط عدّل الملف على GitHub.

- **رابط الملف**: `https://raw.githubusercontent.com/ossamasal2012/yalla-data/refs/heads/main/xtream.json`

> ⚠️ هذا الملف فارغ حالياً بمستودع `yalla-data` (لم يُنشأ بعد). هذا طبيعي تماماً ولا
> يكسر التطبيق: مجلد "سيرفرات Xtream" سيظهر بشارة "0 سيرفر" ورسالة توضيحية بدل أي خطأ،
> إلى أن تنشئ الملف وتضيف أول سيرفر.

## 1) تنسيق الملف

مصفوفة بسيطة، كل عنصر فيها سيرفر Xtream Codes واحد:

```json
[
  {
    "name": "السيرفر الأول",
    "host": "http://example.com:8080",
    "username": "xxxxx",
    "password": "xxxxx"
  },
  {
    "name": "السيرفر الثاني",
    "host": "http://panel2.example.com:25461",
    "username": "yyyyy",
    "password": "yyyyy"
  }
]
```

**شرح الحقول:**
- `name`: الاسم الذي سيظهر بالتطبيق (اختياري — لو تركته فارغاً أو حذفته سيُعطى تلقائياً
  اسم "سيرفر 1"، "سيرفر 2"... حسب ترتيبه بالملف)
- `host`: عنوان لوحة Xtream **كاملاً** بما فيه `http://` أو `https://` ورقم المنفذ
  (نفس القيمة التي تضعها عادة في تطبيقات Xtream الأخرى كـ "Server URL / DNS")
- `username`: اسم المستخدم
- `password`: كلمة المرور

أي عنصر ناقص `host` أو `username` أو `password` يُتجاهَل تلقائياً (لا يظهر بالتطبيق
ولا يوقف تحميل بقية السيرفرات).

## 2) ما الذي يفعله التطبيق بهذه البيانات بالضبط

- **لا شاشة تسجيل دخول منفصلة**: بمجرد ضغط المستخدم على اسم السيرفر، يستخدم التطبيق
  `host`/`username`/`password` مباشرة عبر بروتوكول Xtream Codes API القياسي
  (`player_api.php`) للدخول تلقائياً بالكامل.
- **تاريخ الانتهاء**: يُقرأ من استجابة السيرفر نفسه (`exp_date`) ويُعرض أعلى وأسفل
  شاشة السيرفر مباشرة بعد الدخول (نشط / منتهي / محظور / اشتراك دائم بدون تاريخ).
- **ثلاث مجلدات لكل سيرفر**: البث المباشر، الأفلام، المسلسلات — وكل واحد منها يحتوي
  مجلداً ثابتاً اسمه **"الكل"** بالأعلى دائماً، ثم بقية تصنيفات ذلك السيرفر كما هي
  معرّفة بلوحته.
- **عرض بطاقات مصوّرة (Mobile-first)**: القنوات تظهر كشعارات مربّعة، والأفلام
  والمسلسلات كبوسترات بنسبة 2:3 مع شارة تقييم إن توفرت — كل ذلك بشبكة متجاوبة تتكيف
  مع عرض الشاشة تلقائياً. أي صورة غير متوفرة أو تعذّر تحميلها تُستبدل فوراً ببطاقة
  بيضاء موحّدة يظهر اسم القناة/الفيلم/المسلسل بداخلها بنص أسود، دون أن يؤثر ذلك على
  أي بطاقة أخرى بجانبها.
- **شاشة تفاصيل الفيلم**: الضغط على أي فيلم يفتح شاشة تفاصيل كاملة (صورة/غلاف، تقييم،
  قصة، ممثلون، سنة إنتاج، نوع، مدة، وزر "مشاهدة الإعلان" إن توفر رابط Trailer فعلياً)
  قبل التشغيل — وتُعرض فقط الحقول المتوفرة فعلياً من لوحة Xtream، دون أي قسم فارغ.
- **المسلسلات**: الضغط على مسلسل يفتح شاشة تفاصيله (نفس بيانات الفيلم إن توفرت) ثم
  المواسم كتبويبات أفقية قابلة للتمرير أسفلها، وحلقات الموسم المختار تظهر مباشرة تحت
  التبويبات. التبديل بين المواسم فوري تماماً بدون أي طلب جديد من السيرفر (كل الحلقات
  محمّلة أصلاً دفعة واحدة)، ولا يفتح شاشة أو مستوى تنقل جديد.
- **حفظ موضع التصفح**: الرجوع من تفاصيل فيلم أو مسلسل يعيدك لنفس نقطة التمرير التي
  كنت عندها بالقائمة، دون إعادة تحميلها من الصفر.
- **التشغيل**: كل قناة/فيلم/حلقة يُفتح دائماً عبر تطبيق المشغل الخارجي المختار من
  شاشة الإعدادات — تماماً بنفس آلية القنوات العادية، بدون أي فرق.
- **الأداء**: القوائم الكبيرة جداً (مئات أو آلاف القنوات/الأفلام ببعض السيرفرات) تُعرض
  بتقنية "تمرير افتراضي" (Virtual Scrolling) بحيث لا يُبنى فعلياً بالذاكرة سوى البطاقات
  الظاهرة على الشاشة فقط (+ هامش بسيط)، وصور البطاقات تُحمَّل بتقنية Lazy Loading —
  فتبقى القائمة خفيفة وسريعة حتى على الهواتف الضعيفة ومع آلاف العناصر.

## 3) كيفية إضافة/تعديل سيرفر

1. افتح (أو أنشئ) ملف `xtream.json` في مستودع `yalla-data`
2. أضف كائن السيرفر الجديد بنفس التنسيق أعلاه
3. احفظ الملف وارفعه على GitHub
4. افتح التطبيق (أو اسحب للأسفل للتحديث) — سيظهر السيرفر الجديد تلقائياً داخل مجلد
   "سيرفرات Xtream"

## 4) ملاحظات مهمة

✅ **لا حاجة لتحديث التطبيق**: أي تعديل على `xtream.json` يظهر بالتطبيق فوراً بالتحميل التالي

✅ **تعدد السيرفرات**: أضف بقدر ما تريد من السيرفرات بنفس المصفوفة

✅ **سيرفر معطوب لا يكسر البقية**: لو تعذر الاتصال بسيرفر معيّن (بيانات خاطئة، اشتراك
منتهي، أو السيرفر نفسه متوقف)، يظهر له فقط رسالة خطأ واضحة مع زر "إعادة المحاولة"،
وبقية السيرفرات والمحتوى الآخر بالتطبيق يعمل بشكل طبيعي تماماً

❌ **لا تنشر بيانات حساسة بمستودع عام دون داعٍ**: ملف raw.githubusercontent.com يمكن
لأي شخص لديه الرابط قراءته — إن كانت هذه بيانات اشتراكات مدفوعة يُفضّل أن يكون
مستودع `yalla-data` خاصاً (Private)، بنفس ما ينطبق أصلاً على `channels.json`
