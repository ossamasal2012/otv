# دليل إضافة القنوات لتطبيق يلا گول

## المشكلة التي تم حلها
ملفات m3u8 لا تعمل مباشرة عند رفعها على GitHub Raw لأن:
1. روابط GitHub Raw لها قيود CORS
2. التطبيق يتوقع صيغة JSON محددة وليس m3u8 خام

## الحل المعتمد

### 1. تنسيق القنوات في التطبيق
التطبيق يقرأ القنوات من ملف JSON بصيغة خاصة:

```json
[
  {
    "n": "اسم القناة",
    "c": "تصنيف القناة",
    "s": [
      {
        "n": "اسم السيرفر",
        "u": "رابط البث المباشر",
        "t": "v"
      }
    ]
  }
]
```

**شرح الحقول:**
- `n`: اسم القناة (بالعربية أو الإنجليزية)
- `c`: التصنيف (مثال: "كرة قدم"، "أخبار"، "رياضة إضافي")
- `s`: مصفوفة السيرفرات المتاحة للقناة
  - `n`: اسم السيرفر (اختياري)
  - `u`: رابط البث (URL)
  - `t`: نوع البث ("v" للفيديو المباشر، "i" لـ iframe)

### 2. كيفية إضافة قناة جديدة

#### الطريقة الأولى: تعديل ملف channels.json الرئيسي

1. افتح ملف `channels.json` في مستودع yalla-data
2. أضف كائن القناة الجديد في نهاية المصفوفة
3. احفظ الملف وارفعه على GitHub

**مثال لإضافة قناة "الوان سبورت 1":**

```json
{
  "n": "الوان سبورت 1",
  "c": "رياضة إضافي",
  "s": [
    {
      "n": "سيرفر 1 - HD",
      "u": "http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181661.ts",
      "t": "v"
    },
    {
      "n": "سيرفر 2 - SD",
      "u": "http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181662.ts",
      "t": "v"
    }
  ]
}
```

#### الطريقة الثانية: تحويل ملف m3u8 إلى JSON

إذا كان لديك ملف m3u8 مثل:

```m3u8
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXT-X-MEDIA-SEQUENCE:0

#EXTINF:10.0,ALWAN SPORT 01 HD
http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181661.ts

#EXTINF:10.0,ALWAN SPORT 01 SD
http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181662.ts

#EXT-X-ENDLIST
```

حوّله إلى هذا التنسيق JSON:

```json
{
  "n": "الوان سبورت 1",
  "c": "رياضة إضافي",
  "s": [
    {
      "n": "HD",
      "u": "http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181661.ts",
      "t": "v"
    },
    {
      "n": "SD",
      "u": "http://pro.netmos.ovh:7355/live/MMTVO89S7DY7CNV7SD/P7HIDSPCN580WXH90/181662.ts",
      "t": "v"
    }
  ]
}
```

### 3. مصادر القنوات في التطبيق

التطبيق يحمل القنوات من 3 مصادر:

1. **القنوات الرئيسية**: 
   - URL: `https://raw.githubusercontent.com/ossamasal2012/yalla-data/refs/heads/main/channels.json`
   
2. **قنوات القرآن الكريم**:
   - URL: `https://raw.githubusercontent.com/ossamasal2012/quran/refs/heads/main/quran.json`
   
3. **قصائد حسينية**:
   - URL: `https://raw.githubusercontent.com/ossamasal2012/quran/refs/heads/main/peoms.json`

### 4. ملاحظات مهمة

✅ **لا حاجة لتحديث التطبيق**: بمجرد تحديث ملف JSON على GitHub، ستظهر القنوات الجديدة تلقائياً عند فتح التطبيق

✅ **تعدد السيرفرات**: يمكن إضافة أكثر من سيرفر لكل قناة كاحتياط

✅ **التصنيفات التلقائية**: التطبيق ينشئ تصنيفات تلقائياً بناءً على الحقل `"c"`

✅ **دعم HLS و DASH**: التطبيق يدعم تشغيل روابط .m3u8 و .mpd مباشرة

❌ **لا تستخدم روابط GitHub Raw لملفات m3u8 مباشرة**: لأنها لن تعمل بسبب قيود CORS

### 5. أدوات مساعدة

يمكنك استخدام هذا القالب الجاهز لإضافة قنوات جديدة:

```json
{
  "n": "اسم القناة هنا",
  "c": "التصنيف هنا",
  "s": [
    {
      "n": "سيرفر 1",
      "u": "الرابط هنا",
      "t": "v"
    }
  ]
}
```

### 6. اختبار القنوات

بعد إضافة القناة:
1. ارفع الملف على GitHub
2. انتظر دقيقة لتحديث CDN
3. افتح التطبيق وسحب للأسفل للتحديث
4. ابحث عن القناة في التصنيف الذي أضفته
